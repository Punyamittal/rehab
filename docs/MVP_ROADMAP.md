# MVP & Scaling Roadmap

## Phase 1 — MVP (Current)

**Goal**: Demonstrate core learning loop on low-end devices.

- [x] Project scaffold (Next.js, Tailwind, Framer Motion)
- [x] Warm, child-safe design system
- [x] Hindi-first UI with English toggle
- [x] Student home + module catalog
- [x] Interactive module player (slides, quiz, checkpoints)
- [x] Branching story engine (1 sample story)
- [x] Emotion check-in (pre/post)
- [x] Ambient motion background (calm, non-addictive)
- [x] Facilitator dashboard (mock + API-ready)
- [x] Volunteer guidance flow
- [x] Local progress persistence (demo mode)
- [x] Supabase schema + client setup

**Out of scope for MVP**: Real auth, TTS, AI generation, full offline PWA.

## Phase 2 — Pilot Ready (4–6 weeks)

- Supabase Auth (magic link / PIN for centres)
- Real student profiles per centre
- Hindi TTS integration (Google Cloud / Azure)
- Printable facilitator reports (PDF)
- Service Worker + offline module cache
- 10+ modules across all topics
- Emotion trend charts (7/30 day)

## Phase 3 — Multi-Centre Scale (8–12 weeks)

- Org/centre hierarchy
- Gemini/OpenAI story generation pipeline (reviewed by facilitators)
- Adaptive module recommendations
- Realtime facilitator alerts (disengagement)
- Analytics dashboard (aggregated, privacy-safe)
- Volunteer training certification tracking

## Phase 4 — Long-Term

- Parent/guardian communication (where appropriate)
- Integration with centre MIS
- Low-bandwidth video lessons
- Community-created module marketplace (moderated)
- Impact measurement research exports

## Success Metrics

| Metric | Target (Pilot) |
|--------|----------------|
| Module completion rate | > 70% |
| Avg session length | 3–8 min (micro-learning) |
| Emotion check-in participation | > 90% |
| Facilitator time saved on tracking | 30%+ |
| Student self-reported engagement | Qualitative improvement |
